# Retail Radar – Retail Sales Exploratory Data Analysis

## Project Overview
Retail Radar is a Data Analytics internship project focused on exploring retail sales data to identify sales trends, top-performing products, and business insights using Python.

## Objectives
- Clean and prepare retail sales data.
- Analyze sales performance and product demand.
- Identify trends over time.
- Generate insights to support business decisions.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Structure
- `Retail_Radar_EDA.ipynb` – Exploratory data analysis notebook.
- `data/` – Dataset and dataset instructions.
- `outputs/` – Exported analysis results.
- `requirements.txt` – Required Python packages.

## Dataset
The project uses retail sales transaction data. Refer to `data/README.txt` for the dataset source and download instructions.

## How to Run
1. Install the required packages using `pip install -r requirements.txt`.
2. Download the dataset and place it in the `data/` folder.
3. Open `Retail_Radar_EDA.ipynb` in Jupyter Notebook or JupyterLab.
4. Run the notebook cells in order.

## Project Outcome
The analysis helps identify sales patterns, product performance, and actionable business insights.

# Customer Segmentation Analysis

## Project Overview
This project segments e-commerce customers based on purchasing behaviour using RFM analysis and K-Means clustering.

## Objectives
- Clean and explore retail transaction data.
- Calculate Recency, Frequency, and Monetary metrics.
- Standardize RFM features and apply K-Means clustering.
- Use the Elbow Method to evaluate the number of clusters.
- Visualize customer segments and develop targeted marketing recommendations.

## Technology Stack
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, JupyterLab.

## Dataset
UCI Online Retail dataset. Download it from the [official UCI dataset page](https://archive.ics.uci.edu/dataset/352/online+retail) and place `Online Retail.xlsx` inside the `data/` folder.

## How to Run
1. Install the dependencies listed in `requirements.txt`.
2. Download the dataset and place it in `data/Online Retail.xlsx`.
3. Open `Customer_Segmentation_Analysis.ipynb` in JupyterLab.
4. Run all notebook cells from top to bottom.

## Outputs
The `outputs/` folder contains cleaned data, customer-level RFM segments, cluster profiles, descriptive statistics, and visualization charts.
